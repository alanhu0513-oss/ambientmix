## Features to Showcase

1. **Mix Multiple Sounds** - Click several sounds at once to create layered ambient mixes
2. **Individual Volume Control** - Each playing sound has its own volume slider
3. **Visual Feedback** - Playing sounds get a gradient glow and pulsing indicator
4. **Smooth UX** - Transitions, animations, and responsive design

## Tech Highlights

- **Web Audio API** - Custom AudioManager class handling AudioContext, GainNodes, and looping
- **React + TypeScript** - Type-safe component architecture
- **Tailwind CSS v4** - Modern styling with gradients and animations
- **No dependencies for audio** - Pure browser APIs
